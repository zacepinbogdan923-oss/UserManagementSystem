# UserManagementSystem

Учебное консольное приложение на C# для лабораторной работы «Работа с Git в Visual Studio».

## Запуск

Откройте `UserManagementSystem.csproj` в Visual Studio и нажмите `Ctrl + F5`.

## Файлы

- `Program.cs` — демонстрация работы программы.
- `UserManager.cs` — класс для добавления, удаления и поиска пользователей, а также получения списка.
- `UserManagementSystem.csproj` — файл проекта .NET.

## Как использовать проект для лабораторной по Git

1. Создайте первый коммит с сообщением `Добавлен базовый класс UserManager`. Для соответствия заданию в первом коммите можно оставить в `UserManager.cs` только поле `_users` и метод `AddUser`.
2. Создайте ветку `feature/user-removal`, добавьте `RemoveUser` и демонстрацию удаления в `Program.cs`, затем сделайте коммит.
3. Переключитесь на `main` и внесите отдельное изменение в ту же строку `UserManager.cs`, которую будете менять в ветке функции удаления.
4. В обеих ветках зафиксируйте разные варианты одной и той же строки. После слияния Visual Studio должна показать конфликт. Разрешите его и зафиксируйте слияние.
5. Подключите GitHub-репозиторий как `origin` и выполните Push.

Важно: проект содержит готовую итоговую версию программы. Если нужно показать историю этапов работы в Git, создавайте коммиты по шагам, а не коммитьте все файлы одним первым коммитом.

## Контрольные вопросы

1. **Как создать новую ветку в Visual Studio?**  
   Открыть меню Git или окно «Репозиторий Git», выбрать создание новой ветки, указать имя и переключиться на неё.

2. **Какими способами можно просмотреть историю изменений?**  
   В окне журнала Git в Visual Studio или в истории коммитов на GitHub.

3. **Как разрешить конфликт слияния в Visual Studio?**  
   Открыть список конфликтов, сравнить версии, выбрать или отредактировать итоговый код, подтвердить разрешение и создать коммит слияния.

4. **Как отправить изменения в удалённый репозиторий?**  
   Настроить `origin`, создать коммиты, выполнить Push и проверить файлы на GitHub.
